常见问题

下载之前，
你可能想知道

映剪支持哪些系统？＋

当前正式包面向 Windows 10 / 11 x64。暂未提供 macOS、Linux 或移动端版本。

素材会上传到云端吗？＋

当前剪辑、预览和导出在本地完成。请自行保管工程文件与原始素材，并为重要项目做好备份。

Windows 为什么显示未知发布者？＋

当前安装包尚未进行代码签名，因此 Windows 可能显示未知发布者。请只从本官网或官方 GitHub Releases 下载，并核对页面提供的 SHA256。

怎样确认下载的是完整安装包？＋

在 PowerShell 运行 Get-FileHash .\安装包.exe -Algorithm SHA256，结果应与下载区显示的 SHA256 一致。

在哪里查看历史版本？＋

前往官方 GitHub Releases，可以查看发布说明和全部可用版本。
